## 四、购买域名与 ICP 备案流程

1. **购买域名**：在阿里云/腾讯云等注册商购买域名（.com/.cn 均可）。
2. **购买服务器**：备案要求网站托管在国内服务器（阿里云/腾讯云 ECS 等），备案期间需保持服务器在有效期。
3. **提交备案**：在服务器所在云厂商的备案系统提交 ICP 备案：
   - 备案主体：上海塔伸科技有限公司（企业备案，需营业执照、法人身份证等）；
   - 网站名称建议与备案信息一致（如"服务器压力测试任务编排调度软件"）；
   - 备案审核期间网站通常需保持不可访问或仅展示备案中提示，具体以云厂商指引为准。
4. **备案通过**：拿到备案号后，替换页脚占位并链接到 `https://beian.miit.gov.cn/`（当前已做好链接，仅需替换号码）。
5. **部署上线**：将本目录整体上传服务器，配置 Web 服务即可。

> 如后续涉及在线支付经营行为，可能还需办理经营性 ICP 许可证（ICP 证），请咨询当地通信管理局或云厂商备案顾问。

## 五、服务器部署（Nginx 示例）

## 六、在线支付的真实接入（当前为演示模式）

**现状**：下单页为纯前端演示——订单保存在浏览器 localStorage，支付二维码为占位图，"模拟支付成功"按钮仅用于演示业务流程。页面中已明确标注演示提示。

**申请条件**（微信支付、支付宝均需要）：
- 营业执照（企业主体）
- 法人身份证
- 已完成 ICP 备案的网站域名
- 对公银行账户

**推荐接入步骤**：
1. 先以**对公转账**方式上线收款（无需任何资质等待，页面已支持展示收款账户信息，替换真实账户即可）。
2. 备案通过后，申请微信支付商户号（产品选"Native 扫码支付"）与支付宝（当面付/电脑网站支付）。
3. 增加一个简单后端（Node/Java/PHP 均可），职责：
   - 创建订单（`POST /api/orders`，替代 order.js 中本地生成订单号）；
   - 调用微信支付 v3 API（`/v3/pay/transactions/native`）或支付宝 `alipay.trade.precreate` 生成支付二维码；
   - 接收支付平台异步回调，更新订单状态；
   - 提供订单查询接口。
4. 修改 `js/order.js`：代码中所有需要改造的位置均已用 **【接入点】** 注释标出。

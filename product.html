产品功能

六大核心模块覆盖压测任务全生命周期：从场景编排、任务调度、集群执行，到监控告警与报告分析。

模块一

可视化任务编排

像画流程图一样搭建压测场景。测试人员无需编写调度代码，即可将登录、浏览、下单、支付等多个业务步骤编排为一个完整链路，并定义每一步的加压策略与数据依赖。

  • 拖拽式画布编排，步骤级配置并发数、爬坡时长与持续时间
  • 支持串行、并行、条件分支等多种执行拓扑
  • CSV/参数化数据文件绑定，支持自定义变量与函数
  • 前置/后置脚本（断言、数据加工、环境准备与清理）
  • 场景模板库：一键复用常见业务链路模板
  • 脚本版本管理，任意两个版本之间可快速回滚

场景画布

所见即所得的链路编排视图，整体拓扑一目了然，支持画布缩放与步骤定位。

数据工厂

参数化数据导入、变量管理与测试数据构造工具，解决压测数据准备难题。

模板与复用

沉淀团队场景模板，新人也能快速搭出标准化压测链路。

版本管理

场景脚本纳入版本体系，压测结果与脚本版本双向可追溯。

模块二

智能调度引擎

调度引擎是整个平台的"大脑"，负责把编排好的压测任务在合适的时间、分发给合适的施压节点执行，并在任务失败时按策略自动处理。

  • 定时调度与周期调度：支持 Cron 表达式，预约夜间压测时段
  • 资源自动分配：按任务并发需求自动匹配施压节点，避免资源争抢
  • 任务优先级与执行队列：大促保障任务优先执行
  • 失败重试与断点续跑：节点异常自动迁移任务，减少重头再来
  • 配额与审批：压测任务可配置审批流，防止误压生产环境
  • 执行日历：全局视角查看历史与未来的任务排期

定时/周期调度

预约执行、周期回归，让容量巡检成为常态化机制。

智能资源分配

节点负载感知的任务分发策略，让施压集群利用率最大化。

高可靠执行

失败重试、节点故障迁移与断点续跑，保障长时压测稳定完成。

安全审批

压测任务审批与配额管控，生产环境压测更安心。

模块三

分布式施压与多协议执行

施压集群采用分布式架构，单集群可纳管上百台施压节点；执行层支持主流协议与中间件，覆盖从互联网接口到后台数据体系的完整压测需求。

  • HTTP/HTTPS、WebSocket、TCP/UDP 自定义协议压测
  • gRPC、Dubbo 等微服务框架直连压测
  • JDBC 直连数据库压测，主流关系型与国产数据库适配
  • Kafka、RocketMQ 等消息队列收发压测
  • 阶梯加压、峰值冲击、浪涌、稳定性长跑等加压模型
  • 施压节点一键注册、健康检查与弹性扩缩容

协议全覆盖

从 Web 接口到底层中间件，一套平台完成全栈压测。

多加压模型

阶梯、浪涌、尖峰、长跑，匹配不同业务形态的流量画像。

集群管理

节点注册、健康检查、资源水位监控与弹性扩缩容。

全链路支持

配合链路标记与影子隔离方案，安全实施全链路压测。

模块四

实时监控与自动化报告

压测过程中，业务指标与被压系统的资源指标同屏呈现；压测结束后，系统自动汇总数据生成报告，让"出报告"从半天缩短到三分钟。

  • TPS、吞吐量、响应时间（均值/分位值）、错误率秒级刷新
  • 被压侧服务器 CPU、内存、磁盘 IO、网络带宽联动监控
  • 阈值告警：指标越限即时通知，支持 webhook 对接企业IM
  • 自动报告：测试结论、指标图表、瓶颈建议一键生成
  • 历史趋势对比：同场景多轮压测容量基线沉淀
  • 报告导出与归档，满足验收与审计留存要求

实时监控大屏

压测过程全指标可视，问题出现的第一时间被看见。

智能告警

阈值告警与自定义规则，重要事件不漏报、不轰炸。

自动报告

从数据到结论自动成文，三分钟输出专业压测报告。

基线对比

多轮压测趋势对比，量化每次优化的性能收益。

模块五

集成与扩展

平台不是信息孤岛。开放 API 与插件机制让压测融入企业现有的研发流水线，协议扩展能力让平台跟随业务一起成长。

  • OpenAPI：任务创建、启动、状态查询、报告获取全接口开放
  • CI/CD 集成：Jenkins、GitLab CI 等流水线中自动触发性能门禁
  • 插件化协议扩展：自定义协议 SDK，满足私有协议压测
  • 数据对接：压测结果可推送至企业监控与数据平台

开放 API

全能力接口开放，压测能力编排进企业自动化体系。

DevOps 集成

性能门禁进流水线，性能回归左移到每次提交。

模块六

安全与合规

压测平台掌握着企业核心系统的入口权限，安全设计贯穿产品始终；同时明确产品使用边界，坚守合规底线。

  • 私有化部署：全组件可部署于企业内网，数据不外流
  • 权限体系：基于角色的多级权限与操作审计日志
  • 传输加密：控制通道与数据回传支持加密传输
  • 使用合规：产品仅面向自有或已授权系统的性能测试

权限与审计

多角色权限、操作留痕，满足企业内控与审计要求。

数据安全

私有化部署 + 传输加密，压测数据不出企业边界。
